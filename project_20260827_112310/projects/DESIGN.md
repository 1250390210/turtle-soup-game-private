# DESIGN.md

## 气质与意象

深夜书房，一盏昏黄台灯照亮一本皮质封面的推理笔记本。纸页泛黄，边缘有咖啡渍。空气弥漫着悬疑与好奇——每一道题都是一个等待揭开的谜。

关键词：悬疑、私密、推理、沉浸、克制

## 视觉策略

- 图片方向：不使用照片，纯 UI 驱动。用微妙的纹理（纸张、墨迹）暗示质感
- 图形语言：极简线条图标，细边框卡片，标签用圆角药丸形
- 汤底揭晓：刮刮乐/长按揭示，增加仪式感

## 配色方案

- 背景：深墨色 `#1a1a1f`（深夜书桌）
- 卡片：`#242429`（笔记本纸面）
- 主文字：暖白 `#e8e4df`（台灯下的纸页）
- 次要文字：`#8a8680`（墨迹褪色）
- 主强调色：暗酒红 `#8b2d35`（红汤主题色，按钮/高亮）
- 次强调色：琥珀金 `#c49a3c`（标签/特殊标记）
- 边框：`#333338`（若隐若现的分隔线）

## 字体排版

- 标题/汤面：思源宋体（Noto Serif SC）——增添文学悬疑感
- 正文/UI：系统默认无衬线（PingFang SC / Microsoft YaHei）
- 汤面文字适当放大、行距宽松，营造沉浸阅读感

## 动效与交互

- 卡片悬停：微妙的边框亮度提升 + 轻微上移（2px）
- 页面切换：淡入淡出（300ms ease）
- 汤底揭晓：长按 3 秒渐显 / 刮刮乐效果
- 聊天气泡：逐字打字机效果（AI 回答时）
- 缓动曲线：ease-out 为主，克制不浮夸

## 设计禁忌

- 不要恐怖/血腥视觉元素（骷髅、血迹等）
- 不要明亮/饱和色彩（荧光色、亮蓝、亮绿）
- 不要卡通/可爱风格
- 不要过度动效（弹跳、旋转等）
- 不要渐变背景（保持纯色深沉）
